Fiches HTML des veilles quotidiennes, écrites par les routines cloud.

- `rennes/AAAA-MM-JJ.html` : veille actu Rennes (date = le jour couvert, c'est-à-dire le lendemain du passage).
- `emploi-audiovisuel/AAAA-MM-JJ.html` et `emploi-serveur/AAAA-MM-JJ.html` : veilles emploi (date du passage).
- Chaque dossier a un `index.html` d'archives : ajouter la nouvelle page en tête de la liste, juste après `<!-- LISTE -->`.
- Style unique : `style.css`. Gabarit : `MODELE.html`. Balise noindex obligatoire.
- Aucune donnée personnelle : pas de suivi de candidatures, pas d'employeurs déjà contactés, pas d'adresse ni de téléphone de Selim.
- Pas d'étoiles, pas d'astérisques, pas d'emoji : les niveaux s'écrivent en toutes lettres.
